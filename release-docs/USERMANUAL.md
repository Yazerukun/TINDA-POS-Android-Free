# TINDA POS Free — User Manual

Bisaya / English. This manual covers everyday use of TINDA POS Free on Android.

## 1. Starting the day

1. Open **TINDA POS Free**.
2. Log in as admin or your PIN.
3. Tap **Open Shift**. Enter your **starting cash**.
4. The register is now live.

## 2. Taking a payment

1. Tap the item (or search by name).
2. Choose **Cash**, **GCash**, or **Maya**.
3. Cash: enter amount tendered — change is shown.
4. Tap **Pay**. Receipt printed or shared as received.

## 3. Recording utang (unpaid)

1. Tap **Utang** during checkout.
2. Enter the customer name.
3. Tap **Save as unpaid**.

## 4. Expenses / cash-in / cash-out

1. Open **Register / Shift** tab.
2. Tap **Expenses** to log a cost.
3. Cash-in / cash-out for floats and deposits.

## 5. Closing the day (Z-Reading)

1. Tap **Close Shift**.
2. Review the Z-Reading: gross, discounts, net, refunds, voids, expected cash.
3. Compare your physical cash with **expected cash** listed.
4. Confirm close.

## 6. Updating the app

1. On launch, the app checks GitHub for a newer official version.
2. If one exists, a **"New version available"** pop-up appears.
3. Tap the pop-up / **Update** — the new APK downloads.
4. Android asks to **install the update** — allow it.
5. The update installs **over** the current app and **keeps all your sales data**.

> No need to back up before an update — data is preserved by the same signing key.

## 7. Troubleshooting

| Problem | Fix |
| --- | --- |
| No "new version" pop-up | Check internet; ensure you are online when the app starts |
| Download won't start | The official release must have a `.apk` asset; if only `.exe` files are there, the updater correctly refuses them |
| Install blocked | Allow "install from unknown sources" for your own download |

## 8. Privacy

All sales data is stored **on your device**. TINDA POS Free does not upload your
sales to any server.
