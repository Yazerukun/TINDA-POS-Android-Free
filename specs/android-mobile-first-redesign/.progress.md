## Learnings & Discovered Context
- **Current Issues on Mobile**:
  - `Dashboard`: 2x2 bulky stat cards with huge text, no quick action shortcuts, desktop-style section cards.
  - `Inventory`: Clunky 8-button grid pushing the product list below the fold; lacks a floating action bar or compact mobile drawer.
  - `More`: Bulky list with desktop-style chevrons; needs grouped iOS/Material 3 style cards.
  - `Utang & Tables`: Uses desktop HTML `<table>` elements with 5+ columns that overflow or squish on mobile viewports.
  - `Modals`: Centered floating desktop modals rather than ergonomic mobile bottom sheets.
  - `Navigation & Spacing`: Excessive padding (`p-6`) wasting 48px of width on narrow screens; top bar cramped.
- **Constraints**:
  - Zero feature breakage: Keep 100% of v1.0.27 functionality (TINDA BANTAY 172-item catalog, Dexie v3, Universal Backup, GitHub APK Updater, POS, Utang, etc.).
  - Preserve all existing tests (100/100 Vitest passing).
